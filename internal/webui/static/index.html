02 / Under the hood

One write.
Five boundaries.

The system favors explicit seams over hidden framework behavior. Follow a successful PUT from HTTP request to durable, replicated state.

  1. 01HTTP

    Validate

    The API bounds keys and values, preserves cancellation, and encodes clear failure semantics.

  2. 02LOG

    Propose

    The leader appends a checksummed command and persists it before replication.

  3. 033/5

    Replicate

    AppendEntries moves the command to a majority. Minority copies cannot commit alone.

  4. 04✓

    Apply

    Committed commands execute once, in index order, on the deterministic state machine.

  5. 05204

    Acknowledge

    Success returns only after local application; a timeout is honestly marked ambiguous.

Scope matters.

The 52-scenario catalog is defined and validated, but it is not yet an end-to-end executed suite. The full-cluster 300 ms recovery claim is also unearned. The project’s evidence report says this plainly.
